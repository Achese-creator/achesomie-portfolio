# CoastCast

CoastCast is a full-stack travel weather application.

Features:

- Live weather forecasts
- Destination search
- Google Maps integration
- Meal recommendations
- Search history
- CSV export
- PDF export

Tech Stack:

- Next.js
- React
- Express
- SQLite
- WeatherAPI
- Google Maps API

This project demonstrates full-stack engineering, API integration and backend development.
